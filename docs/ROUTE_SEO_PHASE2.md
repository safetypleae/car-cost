# 전국 지역 검색 SEO 2차 — 콘텐츠 품질 개선

## 적용 범위
- 기존 `/routes` 경로 목록 및 `/routes/[slug]` 상세 페이지만 개선한다.
- 새로운 지역 조합을 임의로 생성하거나 허위 거리·소요시간·통행료를 삽입하지 않는다.
- 경로별로 이미 존재하는 고유 `route.summary`, `routeSpecificContent`를 재사용한다.

## 변경 사항
- 경로 목록의 링크를 "A에서 B까지" 형태의 자연어 문장으로 표현하고, 각 경로의 실제 요약을 함께 보여 준다.
- 목록 페이지에 거리·연료비·통행료·왕복·인원별 비용 계산 방법과 기준 링크를 제공한다.
- 상세 페이지는 이동 목적(공항 / 업무·반복 / 여행·방문)에 맞춰 실제 계산 단계, 관련 계산 도구, 추가 FAQ를 제공한다.
- 관련 경로의 내부 링크도 검색 의도에 맞는 설명 텍스트로 개선한다.
- 기존 사이트맵과 URL은 변경하지 않는다. 페이지 조회만으로 새 API를 호출하지 않는다.

## 배포 후 검증
1. `/routes`의 경로 목록에서 개별 요약과 계산 설명이 표시되는지 확인한다.
2. `/routes/gwangju-yeosu`에서 여행 안내 및 관련 링크가 정상 표시되는지 확인한다.
3. `/routes/seoul-incheon-airport`에서 공항 주차 안내 및 계산기 링크가 정상 표시되는지 확인한다.
4. `/routes/seoul-suwon`에서 반복 이동 안내와 월간 출퇴근 계산기 링크가 정상 표시되는지 확인한다.
5. 각 페이지의 canonical URL, robots 허용, sitemap 포함 여부를 확인한다.
6. Google Search Console / 네이버 서치어드바이저에서 색인·노출·클릭 변화를 추적한다.

**주의:** 빌드 성공과 검색엔진 노출은 별개다. 검색 순위나 색인을 보장하지 않는다.
